# Feeds

The lists in this directory are derived from data published by the [SANS Internet Storm Center](https://isc.sans.edu/) (© SANS ISC) through its [API](https://isc.sans.edu/api/).

Changes from the source: only the IPv4 addresses are kept, and they are collapsed into CIDR ranges, one per line.
